# Спецификация MVP

## Функции

1. Создание задачи с обязательным непустым заголовком.
2. Статусы: `New`, `InProgress`, `Done`.
3. Приоритеты: `Low`, `Normal`, `High`.
4. Изменение статуса с проверкой допустимых переходов.
5. Сохранение и загрузка задач в JSON-файл.
6. Поиск по заголовку.
7. Фильтрация по статусу и приоритету.

## Критерии приёмки

- доменные правила покрыты тестами;
- round-trip JSON сохраняет все данные задачи;
- повреждённый файл даёт понятную ошибку;
- пустой поиск не ломает приложение;
- `dotnet build` и `dotnet test` завершаются успешно.

## Ограничения

Локальный запуск, один пользователь, JSON вместо БД, без сети.
